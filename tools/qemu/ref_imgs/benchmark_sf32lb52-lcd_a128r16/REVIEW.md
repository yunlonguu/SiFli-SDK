# 待审查：当前 QEMU 渲染结果

这些图片由本次增加的固定场景入口批量采集，分辨率 390×450。
独立启动两次 QEMU 后，全部 96 个场景的两张采样均逐像素一致。
这证明结果可重复，不证明全部画面正确。

本轮已启用压缩字体解码、修正 Alpha 图片的整体透明度参数、补齐中间图层数据长度，
并将透明目标、图片重着色及非普通混合交给软件路径处理。
固定文字截图改为一份多行样本，性能动画保留原有全部对象。
压缩文字、ARGB 重着色及减色场景的主体已恢复显示。

当前仍需进一步定位的现象（不是完整缺陷清单）：

- 032、052、054、060、062 等 ARGB 场景仍出现彩色杂纹。
- 001、007、033、038/039 等场景仍缺少主体，部分其他透明度场景也存在异常。
- 同一固件的软件模式可以显示上述主体；需要同编号的硬件 EPIC/软件画面进一步对照。

尚未确定上述异常分别来自测试场景、SDK 渲染适配、资源格式还是 QEMU 模型。
在定位前，CI 只检测相对当前结果的变化；不能将通过标为“全部视觉正确”。
不要仅为让 CI 通过而覆盖这些图片。修复后应检查实际图与差值图，再更新受影响参考图。
